Contact

Feedback, bugs, or ideas.

This studio lives in a static repo and has no backend inbox. If something breaks, an idea surfaced, or a collaboration came to mind, use one of the channels below. Bug reports and feature requests go to GitHub issues; anything requiring a paper trail goes to email.

Ways to reach out

Email

twasinalam71@gmail.com

For general questions, collaboration inquiries, or when you want a paper trail.

GitHub Issues

Bug reports and feature requests.

github.com/twasinalam/titanic-viewcard/issues

Include OS, browser, and a screenshot if possible so the issue can be triaged quickly.

What to mention

  • A layout or render error on a particular screen size or browser.
  • A wrong character-name-to-slot mapping — e.g. uploading a file named bradley when the preset expects brady.
  • A print-alignment issue across browsers on the combined sheet export.

Checked periodically; replies within a few days when possible.
