## About

WHITE STAR SOUVENIR WORKS is a browser-based postcard and viewcard creation project inspired by the RMS Titanic and the 1997 film *Titanic*.

It provides a creative platform for designing personalised Titanic-themed postcards using character portraits, visual templates, and custom text.

The project combines vintage maritime aesthetics with modern web technologies.

## Features

- **Postcard Creation:** Create personalised Titanic-themed postcards and viewcards.
- **Character Collection:** Organise and use Titanic character portraits.
- **Image Uploads:** Add personal images to your designs.
- **Customisation:** Personalise postcard text and visual elements.
- **Design Templates:** Create postcards using different visual layouts.
- **Preview & Rendering:** Preview and render postcard designs using browser-based technology.

## Technology

- HTML5
- CSS3
- JavaScript
- HTML Canvas

## Getting Started

### Use Online

Visit the live website:

https://titanic-viewcard.tiiny.site/

### Run Locally

Clone the repository:

```bash
git clone https://github.com/twasinalam71-spec/titanic-viewcard-generator.git
```

Navigate to the project directory:

```bash
cd titanic-viewcard-generator
```

Open `index.html` in your browser.

Alternatively, use a local development server.
