## ✨ About the Project

**WHITE STAR SOUVENIR WORKS** is a vintage-inspired, browser-based postcard and viewcard creation studio inspired by the timeless elegance of the RMS Titanic era.

It allows users to create personalised, beautifully designed postcards using character portraits, carefully crafted templates, custom messages, and decorative elements.

Whether you're a Titanic enthusiast, a vintage design lover, a postcard collector, or simply someone who enjoys creating meaningful keepsakes, this project provides a creative space to turn your ideas into printable designs.

The experience combines nostalgic maritime aesthetics with modern web technology, making postcard creation accessible across desktop, tablet, and mobile devices.

**No complicated design software. No unnecessary complexity. Just creativity and timeless style.**

---

## 🎨 Design Philosophy

The visual identity of WHITE STAR SOUVENIR WORKS is built around a simple idea:

> Modern convenience, timeless elegance.

The interface takes inspiration from vintage maritime correspondence, traditional postcards, historical travel memorabilia, and the visual atmosphere of the early twentieth century.

### Design Principles

- **Vintage Elegance:** Warm ivory, deep navy, muted gold, and carefully balanced typography.
- **Museum-Inspired Presentation:** A refined visual experience that gives every postcard room to breathe.
- **Content First:** The postcard artwork remains the centre of attention.
- **Minimalism:** No unnecessary interface clutter or distracting animations.
- **Responsive Design:** A comfortable experience on modern desktops, tablets, and smartphones.
- **Performance Conscious:** Lightweight implementation and efficient rendering wherever possible.

## 🚀 Features

### 🖼️ Personalised Postcard Creation

- Create custom Titanic-inspired postcards and viewcards.
- Add personal photographs and character portraits.
- Arrange and customise uploaded images.
- Choose from multiple professionally designed templates.
- Add personalised messages and postcard text.
- Customise decorative elements and postcard details.

### 🎭 Character Portrait Collection

- Character-focused portrait selection.
- Support for a built-in portrait library.
- Upload personal character images.
- Multiple portrait formats, including 3:4 and 1:1.
- Organised image assets for easier management.

### 📝 Postcard Customisation

- Personalised postcard messages.
- Custom recipient and address details.
- Decorative stamps and postmarks.
- Multiple design and layout options.
- Front-side and back-side editing.

### 🖨️ High-Quality Export & Printing

Designed around high-resolution postcard production.

| Print Format |     Dimensions |
| ------------ | -------------: |
| 4 × 6 inches | 1200 × 1800 px |
| 5 × 7 inches | 1500 × 2100 px |
| A6           | 1240 × 1748 px |
| A5           | 1748 × 2480 px |
| 4 × 8 inches | 1200 × 2400 px |

*Pixel dimensions are based on 300 PPI and rounded to whole pixels.*

Additional planned printing capabilities:

- 300-PPI PNG exports.
- Custom print dimensions.
- Front-only and back-only exports.
- Combined postcard sheets.
- Separate front and back pages for duplex printing.
- Image-resolution warnings when uploaded photographs may not be suitable for the selected print size.

**Note:** Actual double-sided printing depends on the printer and its settings.

### 💾 Project Management

Planned project-management capabilities include:

- Automatic project saving.
- Undo and redo.
- Project restoration after reopening the website.
- Export and import projects as ZIP files.
- Preservation of uploaded image assets.
- Versioned project data.

### 📱 Cross-Device Compatibility

The project aims to provide a complete experience across:

- Desktop computers.
- Laptops.
- Tablets.
- Android smartphones.
- iPhones and other modern mobile devices.

The editor is designed to adapt to different screen sizes without sacrificing essential functionality.

## 🛠️ Technology

WHITE STAR SOUVENIR WORKS is designed as a lightweight, browser-based web application.

The current project architecture uses:

- **HTML5** — Application structure.
- **CSS3** — Styling, layout, and responsive design.
- **JavaScript** — Application logic and interactions.
- **HTML Canvas** — Postcard composition and image rendering.

Additional browser technologies and libraries may be used where they provide a clear benefit.

The project prioritises client-side functionality and avoids unnecessary server infrastructure.

## ⚙️ Getting Started

You can explore the live website or run a local copy of the project.

### 1. Visit the Website

Open:

[**https://titanic-viewcard.tiiny.site/**](https://titanic-viewcard.tiiny.site/)

### 2. Run Locally

Clone this repository:

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

Navigate into the project directory:

```bash
cd YOUR_REPOSITORY
```

Open `index.html` in a modern web browser.

Alternatively, use a local development server, such as the VS Code Live Server extension.

No package installation or build process is required for a plain static HTML/CSS/JavaScript setup.
